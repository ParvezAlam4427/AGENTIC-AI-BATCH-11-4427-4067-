# AI Research Assistant — Faculty Research Hub

This is a Python + Gradio web app that helps faculty generate detailed research overviews and insights based on their profile.

## Features
- Login / Signup authentication
- Suggest trending AI research topics
- Generate detailed theoretical research summaries
- Collaboration & grant opportunities
- Future scope and insights

## Deployment
- Built with Python and Gradio
- Deployable on Vercel using the `@vercel/python` runtime
- Set your `GEMINI_API_KEY` in Vercel Environment Variables if using Google Gemini API
